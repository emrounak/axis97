# AXIS97 Enterprises

**Design • Print • Brand • Supply**

AXIS97 Enterprises is a Kolkata-based creative design and event branding enterprise combining creative design, branding systems, print coordination, and customised event supplies.

The website serves as the company's digital presence and commercial catalogue for event branding, institutional supplies, creative services, and quotation enquiries.

---

## About AXIS97

AXIS97 Enterprises works across the complete event collateral workflow — from creative design and branding to coordinated physical production and delivery.

The business supports requirements such as:

- Event branding
- Creative design
- ID cards and event passes
- Lanyards and access credentials
- Wristbands
- Badges
- Certificates
- Banners and backdrops
- Standees and venue signage
- Event registration kits
- Stationery and merchandise
- Book design and publication
- Flex design
- Complete event collateral bundles

Physical production is coordinated through external production and printing partners according to the project requirement.

## Services

### Creative Design
Keynote presentations, marketing collateral, posters, brochures, publications and visual communication.

### Event Branding
Visual branding systems for academic symposiums, fests, conferences and corporate programmes.

### Identity & Access
ID cards, event passes, badges, lanyards and access credentials.

### Print & Production
Banners, backdrops, roll-up standees, signage and institutional event stationery.

### Merchandise
Branded merchandise, event kits, customised accessories, notepads and pin badges.

### Publishing & Media
Books, brochures, magazines, proceedings and related creative print coordination.

### Certificates
Institutional certificates, merit certificates, participation certificates and formal event documentation.

### Sublimation Wristbands
Custom sublimated event wristbands with one-time buckle options.

### Book Publication & Design
Book designing, publication layouts, editorial design, brochures and souvenir publications.

### Flex Designing
High-resolution vector flex designing for hoardings, signage, arches and venue branding.

## Brand Direction

AXIS97 uses a restrained visual identity built around:

- Black
- White
- Neutral greys
- AXIS97 orange: `#F1410B`
- Rounded corners
- Editorial layouts
- Strong typography
- Minimal interface elements

The website intentionally avoids excessive gradients, unnecessary dashboards, fake statistics, fake testimonials and cluttered UI patterns.
